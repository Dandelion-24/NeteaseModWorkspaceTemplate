# source_structures

一键生成类组件的原结构文件与源地图归档，**只读**。

## 约定

- 每个组件一个以 `component_id` 命名的子目录。
- 新组件把原始导出件与源地图压缩包一并收进来，路径登记到 `components/catalog.json` 的 `source_assets`。
- 运行工程与组件 `source_assets/` 只使用**副本**，不从这里直接取用。
- 任何情况下都不在本目录内编辑、覆盖或重新导出文件。

## 为什么要单独留一份原件

运行副本会被修改变量、裁剪或重新导出，一旦出问题就失去了对照。原件用来：

- 核对运行副本的 SHA-256；
- 在结构被误改后重新复制；
- 作为"这个结构最初长什么样"的唯一事实来源。

体检脚本的 `assets` 区域按**文件名**比对运行副本与原件的哈希，文件名不一致会直接漏检，所以复制时保持原名。

## 目录示例

```text
source_structures/
└── <component_id>/
    ├── <name>.mcstructure
    └── <source-map>.zip
```
