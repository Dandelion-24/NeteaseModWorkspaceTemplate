# logs

外部工具导出的运行日志落点，只作排查参考，不属于交付物，也不进任何提交包。

## 约定

- 从 ModPC、MCStudio 或玩家客户端导出的原始日志放这里，文件名带日期与构建号，例如 `2026-10-17_v0.1.0_run1.txt`。
- 原始日志保留原字节，不要重新编码或裁剪；需要摘要就在旁边另写一份 `.md`。
- 结论迁到组件 `ISSUE_HISTORY.md`、`validation/runtime_record.md` 或 `docs/PLATFORM_LESSONS.md`，不要把 `logs/` 当事实来源。

## 日志在哪

- 从当前 MCStudio / 客户端导出入口或本机实际日志目录查找，不预设所有版本的日志路径与内容相同。
- 区分引擎日志与 ModSDK 脚本输出，核对时间、进程、构建与组件前缀，确认采集通道确实包含目标消息。
- 界面错误可能只在覆盖层可见；界面问题同时保存截图。日志没有异常不等于没有故障。
