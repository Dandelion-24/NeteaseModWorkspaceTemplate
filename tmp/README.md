# tmp

一次性脚本与中间产物的工作目录，不属于交付物。

## 规则

- 产物用完即清。正式文档不得把 `tmp/` 下的文件当成事实来源。
- 需要长期保留的结论迁到组件目录、工程 `validation/` 或 `docs/PLATFORM_LESSONS.md`。
- 确实要留下的文件写进下面的清单，注明用途与保留理由，否则下一个人会当噪声删掉。

## 保留清单

| 路径 | 用途 | 理由 |
| --- | --- | --- |
| （暂无） | | |

## 清理

- 删除前核对完整路径，删除后检查是否仍然存在。
- 世界数据副本、原始日志、取证截图不要按扩展名批量删除。
- 临时脚本可以留在 `tmp/` 作为复跑入口，但要写明它对应哪一轮、依赖什么。
