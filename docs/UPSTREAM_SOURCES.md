# 文档来源与使用边界

资料入口是[网易开发者官网](https://mc.163.com/dev/)。详细官方 URL 与本地预期路径见 `SOURCES.json`；索引不包含正文、示例复制件或图片。

`mcdocs/1-ModAPI/` 用于正式 API 查证。beta、历史页面与其他端侧资料分别辨认，不由标题或目录中的数字推定接口支持。源中未出现某页不等于 API 已废弃。

默认从公开官网取得当前正文供本机开发参考，也可导入用户明确指定的可用资料。根 MIT 不覆盖官方内容，不据公开访问推定整库转载或再分发许可。确认存在新的正式版文档或正式离线文件后，按 [README.md](README.md#正式文档与平台版本更新)更新本地资料；不默认将本机缓存发到仓库或 Release。

当前默认目标由 `PLATFORM_BASELINE.json` 记录；确认新正式版后按根规则同步，既有组件兼容与历史证据分别维护。
