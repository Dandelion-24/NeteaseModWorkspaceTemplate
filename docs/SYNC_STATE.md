# 初始文档状态

公开模板只含来源元数据和原创核对方法，没有官方正文或配图。用户确认初始化后，从当前公开官网缓存三个资料家族的正文，或导入使用者指定的本地资料。

实际状态以 `prepare_workspace.py --status` 及本机 `docs/LOCAL_MANIFEST.json` 为准。该清单保存来源、取得范围和哈希，不是官方签名、逐接口核对结果或游戏证据；图片不下载。

`--check-updates` 分别检查正式导航和官方文件元数据；文件实际版本与内容还要按 [OFFICIAL_SETUP.md](../dev_tools/OFFICIAL_SETUP.md) 核对。新正式文件发布后必须更新本地文本，不能用较旧离线包覆盖当前正式资料。

正式导航高于 `PLATFORM_BASELINE.json` 时，按文档与版本更新流程同步默认目标；资源存在不能代替版本核对。
