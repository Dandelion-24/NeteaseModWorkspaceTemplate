# 跨端界面与视觉质量合同

本合同用于实际存在的 JSON UI、菜单与 HUD。**原生风格是默认建议，质量和行为是验收条件。** 用户选择及组件已确定的风格优先；不限定配色、页签数、固定尺寸、色数或分页方式。

## 一、不可省略的验收条件

| 方面 | 必须达到的结果 | 验证方式 |
| --- | --- | --- |
| PC 与手机 | 核心动作两端均可完成，不能只靠悬停、滚轮或未验证的长按；端侧布局可不同，语义与服务端规则一致 | PC GUI Scale 3/4/5、手机横竖屏；未覆盖端明确 NOT_RUN |
| 安全画布与命中 | 按目标设备的紧画布设计；关闭、返回、分页和提交可点，不侵入系统手势区或被键盘遮住 | 不同布局的控件框检查与实际点击/触摸 |
| 菜单结构 | 标题/关闭、内容、主操作、导航和结果各有清楚职责；按复杂度合并或拆页，不要求每屏放齐所有区域 | 页面职责图、阅读与操作顺序检查 |
| 几何和层级 | 内容、文字、数量和操作区不意外遮挡；背景、高亮与文字层级明确；同一行外沿、间距与内边距一致 | 解析锚点、百分比和父子坐标后比较；有意叠层须声明遮挡和输入策略，必要信息与操作仍可达 |
| 可读性 | 实际显示尺寸下可辨识，正文与底色有足够对比；重要内容不靠强缩字号或裁切才能装下 | 长中文/混合名称、大数量、多行状态和实际截图 |
| 状态反馈 | 可操作、按下、选中、禁用、处理中、成功/拒绝能区分；有关键事实文字，不能只变色 | 按适用状态逐项触发，选中状态不被 hover/pressed 覆盖 |
| 生命周期 | 未建好控件树时不刷控件；切页只显示所需内容；关闭后背景、输入与预览按产品约定退出，晚回包不重新开屏 | 首开、快切、关闭、晚回、重进与 UI 重初始化 |
| 数据权威 | 展示不直接改世界；处理中可防重点击，但服务端仍验证并去重；未知结果不盲目重发写操作 | 请求链、超时、重复事件与服务端结果核对 |

## 二、可调整的设计选择

- 默认采用与游戏协调的原生尺度、物品渲染与交互反馈；自定义材质和其他视觉风格同样可用，只要满足上表。
- 页面少时保持简单；内容多时可采用分页、滚动、搜索或分组。选择取决于内容与双端输入，不把某一种形式当作唯一正确做法。
- 同一组件建立可复用的外框、间距、字体、图标与状态样式；相近页面保持可预测。详情、设置与返回关系清楚，避免为同一功能堆重复入口或无意义叠层。
- 图标和模型在小尺寸下先有清楚轮廓与识别重点，材质和细节服务于内容。大图和复杂场景按用途安排多个视觉重点，不强制全部素材使用同一图案结构。
- 长文字优先调整文案、独立详情、合理换行或分页；省略时保留可访问的完整信息。普通状态提示不挤占标题、关闭和主操作。
- 主要操作、危险操作与普通导航有清楚区分；需要确认或撤销的行为由数据损失风险决定，不给普通操作统一添加确认框。

## 三、实现中容易写错的边界

- 复用模板须核对真实定义、子控件、变量作用域与绑定；`button + child label` 是可选的清晰基线，继承按钮也可使用。不能仅凭 `@common.button` 或 `$变量` 出现就认定错误。
- JSON 锚点、百分比尺寸描述、像素与 UI 单位分别处理；没有可靠测量时不用猜测的画布值定位。固定宽窄布局和响应式布局均需验证其最紧画布。
- 九宫切片、`keep_ratio`、裁剪和字体缩放按实际纹理和正文配置。裁剪只能限制预期溢出，不能隐藏必要文案或掩盖几何错误。
- 页背景、图标和装饰随所属页/控件一起显示隐藏；显式声明常驻层。图标/文字是否接收输入由交互目标决定，装饰不可意外吞掉按钮点击。
- 用户关闭可以停止本地展示与刷新，但不表示服务器事务已撤销；保留必要对账，过期回包不覆盖新会话或恢复旧页面。
- 输入框考虑焦点、中文输入、键盘出现、保存失败保留输入以及关闭清理；触屏不能依赖桌面悬停提示才能理解操作。

## 四、按风险验证

纯文字小修检查所影响的宽度和状态，不强制重做全部页面。新布局、交互或资源替换覆盖受影响端侧与状态；跨端结构更改需覆盖全部目标布局。

代表性样例包括空内容、最长实际名称、中文/数字混排、大数量、禁用原因、处理中、失败、部分完成、快速翻页、输入法、关闭后晚回和重进。选择与任务相关的项，未使用的能力标 N/A 并说明理由。

静态检查证明结构、路径、状态入口和几何关系；宿主测试证明逻辑分支；游戏截图与实际操作证明渲染、命中和输入。三类结果分别记录，不因换一种风格而判错，也不因静态全绿而跳过必要的游戏验收。
